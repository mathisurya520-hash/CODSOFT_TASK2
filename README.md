# CodSoft Data Science Internship – Task 2

## Exploratory Data Analysis (EDA) on Retail Sales Dataset

### Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand customer purchasing behaviour, identify sales trends, explore relationships between variables, and generate meaningful business insights.

### Dataset Information
- **Dataset:** Retail Sales Dataset
- **Total Records:** 1,000
- **Total Columns:** 9
- **Data Source:** Kaggle

### Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Tasks Performed
1. Loaded the retail sales dataset using Pandas.
2. Inspected dataset structure, columns, and data types.
3. Checked for missing values and duplicate records.
4. Converted the Date column into datetime format.
5. Examined descriptive statistics.
6. Analyzed product categories and gender-wise sales.
7. Visualized transaction amounts using histograms.
8. Used boxplots to identify potential outliers.
9. Explored relationships between numerical variables using scatter plots and correlation heatmaps.
10. Exported the dataset and generated an EDA summary report.

### Key Findings
- The dataset contains 1,000 transactions and 9 columns.
- No missing values or duplicate records were found during the initial inspection.
- The average customer age is approximately 41.39 years.
- The average transaction amount is 456.
- Clothing is the most frequent product category, with 351 transactions.
- Visualizations were used to explore sales distributions, customer demographics, and relationships between numerical variables.

### Visualizations
- Product Category Distribution
- Transaction Amount Distribution
- Total Sales by Gender
- Customer Age vs. Transaction Amount
- Correlation Heatmap
- Transaction Amount Outlier Analysis

### Project Files
- `EDA_Task2.ipynb` – Google Colab notebook containing the analysis and visualizations.
- `EDA_Report.txt` – Summary of the analysis.
- `cleaned_retail_sales_dataset.csv` – Exported dataset with the Date column converted to datetime format.

### Conclusion
This project demonstrates how Exploratory Data Analysis can be used to understand retail transactions, customer demographics, and product purchasing patterns. The analysis provides a foundation for further business intelligence and data-driven decision-making.
